# Public-data and media rules

Only synthetic examples belong in this repository. Source files, tests, screenshots,
issues, and pull requests must not contain information copied from a real deployment.

Never publish a person's name or alias, profile image, account identifier, endpoint,
schedule, receipt, recipient record, database content, credential, or incident capture.
Replace every demonstration value with an obviously fictional value under an
`example.test` or `example.invalid` domain.

Do not add photographs, recordings, logos, fonts, or other media unless the project
has documented redistribution rights and a continuing product need for the file.
Removing metadata is not a substitute for permission.

Operators remain responsible for the data in their own installation. They should
collect the minimum needed, restrict access, set retention and deletion rules, and
follow the laws and service terms that apply to their deployment.
